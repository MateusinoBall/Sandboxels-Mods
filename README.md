## Sobre / About

Bem-vindo ao Sandboxels-Mods! Este repositório contém uma coleção de mods leves para Sandboxels, criados por Mateusino Ball. Os mods visam melhorar, personalizar e adicionar pequenas funcionalidades ao jogo sem complicações.

Welcome to Sandboxels-Mods! This repository contains a collection of lightweight mods for Sandboxels by Mateusino Ball. The mods aim to tweak, customize, and add small features to the game with minimal fuss.

---

## Instalação (3 passos) / Installation (3 steps)

1. Clone ou baixe o repositório:

   git clone https://github.com/MateusinoBall/Sandboxels-Mods.git

2. Copie o(s) mod(s) desejado(s) para a pasta `mods` do Sandboxels.

3. Inicie o jogo e ative o(s) mod(s) em Settings → Mods.
