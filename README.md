## 🚀 Quick Start

### For First-Time Contributors (5 minutes!)

```bash
# 1. Fork & Clone
git clone https://github.com/YOUR-USERNAME/Sandboxels-Mods.git
cd Sandboxels-Mods

# 2. Create your mod
touch mods/my-awesome-mod.js

# 3. Write JavaScript (example)
echo "// Your mod code here" >> mods/my-awesome-mod.js

# 4. Commit & Push
git add .
git commit -m "Add: My Awesome Mod"
git push origin main

# 5. Open a PR
# 🎁 Your exclusive GIF will be generated automatically!
```

### For Experienced Developers

1. **Fork** this repository
2. **Create a feature branch**: `git checkout -b feature/your-mod-name`
3. **Develop your mod** in the `mods/` folder
4. **Test thoroughly** in Sandboxels
5. **Submit a PR** with:
   - Clear description of your mod
   - Usage examples
   - Any dependencies or requirements
6. 🎁 **Receive your exclusive celebration GIF!**
