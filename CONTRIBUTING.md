# Contributing

Obrigado pelo interesse em contribuir com o Sandboxels-Mods! Abaixo está um guia rápido para começar.

1. Fork do repositório e clone sua cópia:

   git clone https://github.com/seu-usuario/Sandboxels-Mods.git

2. Crie uma branch para sua mudança:

   git checkout -b feature/nome-da-feature

3. Faça mudanças pequenas e focadas. Adicione testes ou instruções de teste quando fizer alterações no mod.

4. Commit e push:

   git commit -m "Descreva sua mudança em poucas palavras"
   git push origin feature/nome-da-feature

5. Abra um Pull Request neste repositório e preencha a checklist no template.

Dicas:
- Siga o padrão de estilo do projeto (JavaScript, se aplicável).
- Descreva claramente o problema que a PR resolve ou a feature que adiciona.

Obrigado — sua ajuda é muito bem-vinda!
