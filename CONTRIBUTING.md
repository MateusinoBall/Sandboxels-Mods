# 🤝 Contributing to Sandboxels-Mods

Thank you for your interest in contributing to Sandboxels-Mods! This guide will help you get started.

## 🎯 Ways to Contribute

### 1. 🆕 Create a New Mod
- Design original mods with unique mechanics
- Follow the mod creation guidelines
- Test thoroughly before submitting
- Include documentation and examples

### 2. 🐛 Report Bugs
- Find a bug? Open an issue with:
  - Clear description
  - Steps to reproduce
  - Expected vs actual behavior
  - Screenshots if applicable

### 3. 🔧 Improve Existing Mods
- Optimize code
- Fix bugs
- Add features
- Improve documentation

### 4. 📖 Improve Documentation
- Fix typos
- Add clarifications
- Create tutorials
- Add examples

## 📋 Submission Guidelines

### Before You Start
1. Check existing issues and PRs to avoid duplicates
2. Fork the repository
3. Create a feature branch: `git checkout -b feature/your-mod-name`

### Code Standards
```javascript
// Use clear, descriptive variable names
// Add comments for complex logic
// Test your code thoroughly
// Follow existing code style
```

### Commit Messages
- Use clear, descriptive messages
- Start with emoji: ✨ (new), 🐛 (fix), 📚 (docs), ⚡ (improve)
- Example: `✨ Add new explosive mod with chain reactions`

### Pull Request Process
1. Update README.md if adding new features
2. Add comments explaining your mod
3. Write a clear PR description
4. Include before/after screenshots if applicable
5. Link any related issues

## ✅ Pull Request Checklist

Before submitting your PR:
- [ ] Code follows the style guidelines
- [ ] All functions are documented
- [ ] Mod has been tested in Sandboxels
- [ ] README updated if necessary
- [ ] No console errors
- [ ] PR description is clear

## 🎨 Mod Template

```javascript
 */

// Your mod code here
// Make it creative and fun!
```

## 📅 Review Timeline

- **Days 1-2:** Initial review
- **Days 2-5:** Feedback and adjustments
- **Day 5:** Merge if approved

Keep your fork updated to receive all corrections!

## 🚫 What NOT to Do

- Don't copy other people's mods without credit
- Don't submit spam or irrelevant content
- Don't use offensive language or content
- Don't modify other people's mods without permission

## 💬 Questions?

- Open an issue for questions
- Check existing discussions first
- Be respectful and constructive
